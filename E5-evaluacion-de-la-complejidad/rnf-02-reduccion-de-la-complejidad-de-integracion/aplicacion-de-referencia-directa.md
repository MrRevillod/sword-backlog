# Aplicación de referencia sobre las librerías directas

- **Tipo:** tarea
- **Objetivo:** OE-3
- **Categoría:** evaluación
- **Prioridad:** heredada de RNF-02 (must)
- **Esfuerzo:** L
- **Etapa:** 3
- **Estado:** en-progreso
- **Pertenece a:** RNF-02 Reducción de la complejidad de integración
- **Restricciones:** misma funcionalidad que la variante Sword.

**Objetivo de la tarea**

Construir la misma aplicación directamente sobre las librerías, para tener la línea
base.

**Descripción técnica**

Implementación equivalente sin Sword, usando Axum, Tonic y las bibliotecas del
ecosistema directamente.

**Producto esperado**

Aplicación ejecutable que sirve de línea base para la comparación.

**Justificación**

La comparación necesita una línea base funcionalmente equivalente.

**Criterios de aceptación**

- [ ] implementa la misma funcionalidad
- [ ] no usa Sword
- [ ] compila y funciona
