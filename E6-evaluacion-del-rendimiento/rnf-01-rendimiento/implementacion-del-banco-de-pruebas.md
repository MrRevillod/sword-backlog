# Implementación del banco de pruebas

- **Tipo:** tarea
- **Objetivo:** OE-4
- **Categoría:** evaluación
- **Prioridad:** heredada de RNF-01 (must)
- **Esfuerzo:** M
- **Etapa:** 3
- **Estado:** en-progreso
- **Pertenece a:** RNF-01 Rendimiento
- **Restricciones:** ambas variantes con el mismo perfil.

**Objetivo de la tarea**

Implementar un banco ejecutable para ambas variantes, para obtener las mediciones.

**Descripción técnica**

Scripts que levantan cada variante con el mismo perfil de compilación y las mismas
funcionalidades habilitadas, y ejecutan los escenarios con la misma ventana y duración.

**Producto esperado**

Banco reproducible que corre sobre ambas variantes.

**Justificación**

Un banco reproducible es la base de la evidencia.

**Criterios de aceptación**

- [ ] el banco corre sobre ambas variantes
- [ ] usa el mismo perfil y los mismos datos
- [ ] usa la misma ventana y duración
