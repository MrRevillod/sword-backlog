# Publicación del sitio de documentación

- **Tipo:** tarea
- **Objetivo:** OE-2
- **Categoría:** documentación
- **Prioridad:** heredada de RF-20 (should)
- **Esfuerzo:** S
- **Etapa:** 2
- **Estado:** en-progreso
- **Pertenece a:** RF-20 Documentación y ejemplos
- **Restricciones:** accesible públicamente.

**Historia de usuario**

Como usuario del framework, quiero el sitio publicado, para consultar la documentación
desde cualquier lugar.

**Descripción técnica**

Despliegue del sitio de documentación con las guías y ejemplos navegables.

**Justificación**

La documentación solo cumple su función si es accesible.

**Criterios de aceptación**

- [ ] el sitio queda publicado por URL pública
- [ ] la navegación incluye guías y ejemplos
- [ ] el build y la previsualización funcionan desde el repositorio
