# [RF-20] Documentación y ejemplos

- **Tipo:** requerimiento · **ID:** RF-20
- **Objetivo:** OE-2
- **Categoría:** documentación
- **Prioridad:** should
- **Esfuerzo:** M
- **Etapa:** 3
- **Estado:** en-progreso
- **Depende de:** RB-09
- **Restricciones:** ejemplos ejecutables.

**Relación con los objetivos específicos**

OE-2 — Es la cara pública de la documentación; sostiene la adopción y la
reproducibilidad.

**Historia de usuario**

Como usuario del framework, quiero referencias de API y ejemplos reproducibles, para
adoptar el framework sin depender de conocimiento externo.

**Descripción técnica**

Referencias de API, guías por mecanismo y ejemplos reproducibles, publicados en el
sitio.

**Justificación**

La adopción depende de poder probar el framework por cuenta propia.

**Criterios de aceptación**

- [ ] hay referencias de API publicadas
- [ ] hay ejemplos reproducibles por mecanismo
