# Guías y ejemplos reproducibles por mecanismo

- **Tipo:** tarea
- **Objetivo:** OE-2
- **Categoría:** documentación
- **Prioridad:** heredada de RF-20 (should)
- **Esfuerzo:** M
- **Etapa:** 2
- **Estado:** en-progreso
- **Pertenece a:** RF-20 Documentación y ejemplos
- **Restricciones:** dos idiomas.

**Historia de usuario**

Como usuario del framework, quiero una guía práctica por mecanismo, para integrarlo sin
adivinar.

**Descripción técnica**

Guías por mecanismo que referencian ejemplos ejecutables en `examples/`, en español e
inglés.

**Justificación**

Las guías son el puente entre la referencia y el uso real.

**Criterios de aceptación**

- [ ] cada mecanismo tiene guía práctica
- [ ] cada guía referencia un ejemplo reproducible
- [ ] las guías están en dos idiomas
