# E3 · Desarrollo del framework

- **Tipo:** epic
- **Objetivo:** OE-2
- **Categoría:** framework
- **Prioridad:** must
- **Esfuerzo:** L
- **Etapa:** 2–4
- **Estado:** en-progreso
- **Contenido:** RF-01 … RF-20

**Relación con los objetivos específicos**

OE-2 — Diseñar, desarrollar y documentar Sword. Esta épica reúne las capacidades
funcionales del framework: composición, configuración, mecanismos de comunicación,
funcionalidades transversales y herramientas de desarrollo.

**Descripción**

Conjunto de capacidades funcionales implementadas sobre la base (E2), con un modelo
declarativo común a todos los mecanismos.

**Justificación**

Es el núcleo de la solución propuesta: sin estas capacidades no hay framework que
evaluar en OE-3 y OE-4.

**Criterios de aceptación**

- [ ] los veinte requerimientos funcionales cumplidos
- [ ] los mecanismos comparten el modelo de composición
- [ ] cada capacidad tiene criterios observables
