# [RF-17] Documentación de la API

- **Tipo:** requerimiento · **ID:** RF-17
- **Objetivo:** OE-2
- **Categoría:** framework
- **Prioridad:** could
- **Esfuerzo:** M
- **Etapa:** 4
- **Estado:** en-progreso
- **Depende de:** RF-06
- **Restricciones:** declarada desde la configuración.

**Relación con los objetivos específicos**

OE-2 — Facilita la adopción al exponer la API de forma estándar.

**Historia de usuario**

Como usuario del framework, quiero servir la especificación OpenAPI declarada desde la
configuración, para documentar la API de forma estándar.

**Descripción técnica**

Publicación de la especificación OpenAPI declarada en la configuración, servida con
Swagger UI.

**Justificación**

Documentar a mano se desactualiza.

**Criterios de aceptación**

- [ ] la API se publica en formato OpenAPI desde la configuración
