# Aplicación de ejemplo con al menos dos módulos

- **Tipo:** tarea
- **Objetivo:** OE-2
- **Categoría:** framework
- **Prioridad:** heredada de RF-01 (must)
- **Esfuerzo:** S
- **Etapa:** 2
- **Estado:** en-progreso
- **Pertenece a:** RF-01 Organización modular
- **Restricciones:** reproducible.

**Historia de usuario**

Como usuario del framework, quiero un ejemplo con varios módulos, para ver cómo se
compone una aplicación real.

**Descripción técnica**

Aplicación de ejemplo con dos módulos de responsabilidades distintas que el framework
monta al arrancar.

**Justificación**

Valida el modelo de composición de extremo a extremo.

**Criterios de aceptación**

- [ ] la app define al menos dos módulos distintos
- [ ] las piezas de ambos quedan disponibles
- [ ] compila, inyecta y levanta sin pasos extra
