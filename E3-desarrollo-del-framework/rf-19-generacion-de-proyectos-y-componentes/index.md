**Relación con los objetivos específicos**

OE-2 — Reduce el trabajo inicial de estructuración, una convención de Laravel y NestJS.

**Historia de usuario**

Como usuario del framework, quiero generar proyectos y componentes desde la línea de
comandos, para reducir el trabajo inicial de estructuración.

**Descripción técnica**

CLI que genera proyectos y componentes a partir de plantillas.

**Justificación**

El andamiaje inicial se genera, no se escribe a mano.

**Criterios de aceptación**

- [ ] la CLI genera un proyecto y un componente a partir de una plantilla
