# CLI de proyectos

- **Tipo:** tarea
- **Objetivo:** OE-2
- **Categoría:** framework
- **Prioridad:** heredada de RF-19 (could)
- **Esfuerzo:** M
- **Etapa:** 4
- **Estado:** en-progreso
- **Pertenece a:** RF-19 Generación de proyectos y componentes
- **Restricciones:** plantilla reproducible.

**Historia de usuario**

Como usuario del framework, quiero crear un proyecto desde la terminal, para empezar con
la estructura ya armada.

**Descripción técnica**

Comando que genera un proyecto Sword a partir de una plantilla, con la estructura de
archivos y la configuración inicial.

**Justificación**

Empezar de cero repite decisiones que el framework ya tomó.

**Criterios de aceptación**

- [ ] la CLI genera un proyecto a partir de una plantilla
- [ ] el proyecto generado compila y arranca
