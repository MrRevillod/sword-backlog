# Verificar la cobertura de las guías por mecanismo

- **Tipo:** tarea
- **Objetivo:** OE-2
- **Categoría:** documentación
- **Prioridad:** heredada de RNF-06 (should)
- **Esfuerzo:** M
- **Etapa:** 2
- **Estado:** en-progreso
- **Pertenece a:** RNF-06 Documentación completa y reproducible
- **Restricciones:** todos los mecanismos cubiertos.

**Historia de usuario**

Como usuario del framework, quiero que cada mecanismo tenga su guía, para no encontrar
huecos en la documentación.

**Descripción técnica**

Revisión de que existan guías y referencias para cada mecanismo (HTTP, gRPC, Socket.IO,
eventos) en los dos idiomas.

**Justificación**

Una guía faltante obliga a leer el código para usar una capacidad documentada.

**Criterios de aceptación**

- [ ] cada mecanismo tiene su guía
- [ ] la cobertura es equivalente en ambos idiomas
