# E4 · Calidad y documentación

- **Tipo:** epic
- **Objetivo:** OE-2
- **Categoría:** framework
- **Prioridad:** should
- **Esfuerzo:** M
- **Etapa:** 2–3
- **Estado:** en-progreso
- **Contenido:** RNF-04 … RNF-08

**Relación con los objetivos específicos**

OE-2 — Diseñar, desarrollar y documentar Sword. Esta épica reúne las propiedades no
funcionales del framework (extensibilidad, seguridad, documentación, mantenibilidad y
compatibilidad) que sostienen su calidad y su adopción.

**Descripción**

Propiedades transversales del framework: acceso a las bibliotecas subyacentes,
garantías del lenguaje, documentación reproducible, organización modular con
verificación continua y compatibilidad declarada.

**Justificación**

Un framework con capacidades funcionales pero sin estas propiedades no se mantiene ni
se adopta.

**Criterios de aceptación**

- [ ] las cinco propiedades no funcionales tienen criterios observables
- [ ] la documentación está publicada y es reproducible
- [ ] la compatibilidad está declarada y verificada
