# Verificar el registro sin pasos manuales

- **Tipo:** tarea
- **Objetivo:** OE-2
- **Categoría:** framework
- **Prioridad:** heredada de RB-02 (must)
- **Esfuerzo:** S
- **Etapa:** 1
- **Estado:** hecho
- **Pertenece a:** RB-02 Registro declarativo y automático
- **Restricciones:** sin configuración extra del proyecto.

**Historia de usuario**

Como usuario del framework, quiero que declarar baste para registrar, para no
configurar nada extra.

**Descripción técnica**

Comprobar que declarar un controlador o componente lo deja disponible sin registrar
nada a mano ni ajustar el proyecto.

**Justificación**

Si el registro exigiera pasos extra, la ventaja declarativa se pierde.

**Criterios de aceptación**

- [ ] declarar registra sin pasos manuales
- [ ] no se requiere configuración adicional
